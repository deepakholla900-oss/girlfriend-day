FOR KEERTHI — A LITTLE LOVE NOTE ♡

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html. For the best development experience, use the VS Code extension "Live Server" and click "Go Live".
4. To test mobile layout, open the page in Chrome and press F12, then click the phone/tablet icon. You can also open the site on your phone using Live Server's network URL while both devices are on the same Wi-Fi.

HOW TO SHARE
- Easiest: upload the extracted folder to a static hosting service such as Netlify Drop (https://app.netlify.com/drop) or GitHub Pages.
- Netlify Drop: sign in if prompted, drag the extracted project folder (or a ZIP of its contents, depending on the page's current instructions) into the upload area, then share the public URL it gives you.
- You can also send the ZIP to someone, but they will need to extract it and open index.html.

WHAT'S INCLUDED
- Six responsive sections: Home, Our Story, Reasons, Memories, A Letter, and Forever.
- Responsive navigation for desktop and mobile.
- Tap-to-reveal love notes, a memory carousel, a little synthesized melody, and a final rose/heart surprise.
- The couple and decorative artwork are drawn as inline SVG/CSS, so there are no missing image files to manage.
- Google Fonts are loaded online; if offline, the page falls back to system fonts.

PERSONALIZE IT
- Edit the wording directly in index.html.
- Replace the four memory illustrations with personal photos if you'd like. Keep a backup before editing.
- For a truly personal touch, add your own photos and a message only the two of you understand.
